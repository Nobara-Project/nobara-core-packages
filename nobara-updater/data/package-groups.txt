Nobara 44 kickstart package groups
==================================

Scope: the nine *.ks files directly under ISO-ready-flattened-kickstarts/44/.
The WIP/ directory is excluded. The original comps-group selectors are expanded
using the available Nobara 44 comps metadata. Expansion matches a plain @group
selection: mandatory and default members are included; optional members and
conditional members whose requirements are absent are not forced. RPM dependencies
outside those groups are not expanded.

Rules:
- "kernel" contains only kernel packages explicitly present in all nine files.
- "system core packages" covers the bootloader/initramfs path, live-boot support,
  boot-capable filesystem and storage support, platform firmware, console authentication,
  and the minimum administrative path needed after reaching a shell.
- "graphic stack" contains the native Wayland runtime selectors needed to reach a
  graphical session plus every explicit Mesa or NVIDIA selector, including 32-bit,
  CUDA/OpenCL, monitoring, control, and compatibility packages. Unrelated graphics
  utilities and build-only packages are classified as non-essential here.
- "desktop environment" is the union of the hand-expanded KDE/GNOME desktop groups plus
  their explicit session, audio, integration, theme, font, and core desktop utilities.
- "Non-essential packages" is the exact residual inventory. It means "not assigned above,"
  not "safe to remove"; it includes variant-specific and installer packages.
